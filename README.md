# python-security-scripts

Python scripts and small tools I write while learning security auditing. Each script is documented and tested only against systems I own or have permission to test (labs, wargames, local setups).

## Structure
```
python-security-scripts/
├── README.md
├── port_scanner/        # example: simple TCP port scanner
├── log_parser/          # example: parsing and filtering logs
└── ...
```

Every folder contains its own `README.md` with a description, usage example and what I learned
